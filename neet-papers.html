HOW WE WILL BUILD THIS SECTION

PYQs Should Become a Learning System

01 · Identify

Each question will be mapped to the correct subject, chapter and official syllabus area.

02 · Understand

We will explain the concept being tested instead of only giving the final answer.

03 · Analyse

Repeated concepts, common traps, difficulty and NCERT connections can then be studied properly.

04 · Practise

Later, aspirants can practise PYQs chapter-wise instead of searching through many full papers.

PYQ LEARNING LENS

Types of Questions You Will Learn to Recognise

These are Sathyagrahi Academy learning categories for PYQ analysis — not official NTA question classifications. They help an aspirant understand how the same syllabus can be tested in different ways.

P
PHYSICS

Think → Apply → Calculate

Concept / Principle Based Formula Application Numerical Calculation Graph / Diagram Interpretation Multi-Concept Application Experimental / Measurement Based

Physics questions often test whether you can identify the right concept, connect quantities and apply it accurately under time pressure.

C
CHEMISTRY

Recall → Connect → Apply

Physical Chemistry Numericals Inorganic NCERT Fact / Trend Organic Reaction / Product / Reagent Structure & Bonding Statement / Concept Application Practical Chemistry Based

Chemistry changes its questioning style across Physical, Inorganic and Organic Chemistry, so PYQ analysis should separate these patterns clearly.

B
BIOLOGY

Read → Recall → Differentiate

Direct NCERT Line Based Statement Based Diagram / Label Based Match / Sequence / Classification Example / Exception Based Concept Application

Biology rewards precise NCERT understanding. Similar terms, examples, exceptions and statements often need careful distinction.
